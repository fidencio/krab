# KRAB demos

Runnable examples of products built with the shared KRAB website and CLI.
Each demo supplies branding, colours, available choices, and defaults through a
product profile, without a separate frontend or generation engine.

- [Confidential Containers](confidential-containers/README.md): a CoCo-branded
  preview for Rust runtimes, including Intel TDX, AMD SNP, IBM Secure Execution,
  NVIDIA confidential GPUs, and the development runtime.

See [self-hosting](../docs/self-host.md) for the complete profile reference.
